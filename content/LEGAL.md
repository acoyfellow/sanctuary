# Legal Boundaries

- This project must **not** bundle, link to, or distribute any Diablo 2 / D2R assets, installers, MPQs, ROMs, keys, hashes, or derivative content.
- Users must supply their own legitimately obtained game files; the repo only documents how to point tooling at user-provided assets.
- No reverse-engineered or decrypted Blizzard content should be committed or referenced.
- Use this code in compliance with Blizzard’s terms, applicable law, and DMCA safe practices.
- If uncertain, stop and request human review before proceeding.
